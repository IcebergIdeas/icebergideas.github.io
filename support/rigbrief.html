RigBrief Support

RigBrief is a live-performance setlist app for guitarists. Organize songs, build named setlists, transpose on stage, and navigate chord sections quickly during rehearsals and gigs.

Getting Started

  1. Launch RigBrief. The Demo setlist includes three sample songs.
  2. Use All on Home to browse your library and check songs into the selected setlist.
  3. Switch to Setlist to preview only the active setlist before tapping Start Set.
  4. Import your own library with the download button on Home (JSON export from another device or backup file).

Common Tasks

  • Multiple setlists: Use the setlist picker on Home to create, rename, switch, or delete setlists. The Demo setlist cannot be deleted.
  • Add or edit a song: Tap + to add a song, or the pencil icon on a row to edit.
  • Transpose a song: On the performance dashboard, use the key controls to shift chords up or down by semitone.
  • Export your library: Tap the upload button on Home to export songs and setlists as JSON.
  • Song notes: Open notes from the dashboard while performing. Notes are saved on your device.

Import / Export Format

RigBrief uses a JSON library file. Current exports use schema version 2 and include your songs, named setlists, and selected setlist ID. Older v1 files that only include activeSetlistSongIDs are still supported.

Bundled Content

The app ships with three RigBrief demo songs only. Any other charts or setlists are added by you through import or manual entry and remain on your device unless you export them.

Troubleshooting

  • Empty set after Start Set: Make sure the selected setlist has songs checked in, or switch the Home filter to Setlist to confirm.
  • Import failed: Confirm the file is valid RigBrief JSON. Try Merge instead of Replace if you want to keep existing songs.
  • Screen sleeps during performance: RigBrief keeps the screen awake while the dashboard is open. Return to Home if you are not performing.
